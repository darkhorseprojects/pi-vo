# OmniVoice voice tags

Use this only when writing text meant for the `voice_say` tool.

Supported expressive tags include `[laughter]`, `[sigh]`, `[confirmation-en]`, `[question-en]`, `[question-ah]`, `[question-oh]`, `[question-ei]`, `[question-yi]`, `[surprise-ah]`, `[surprise-oh]`, `[surprise-wa]`, `[surprise-yo]`, and `[dissatisfaction-hnn]`.

Keep tags sparse. Put them where the sound should occur, not as a prefix for every sentence.
